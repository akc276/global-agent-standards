# Global Agent Rule: Documentation, README & Logbook SOP

> **Scope:** Generic User Standard (Portable to any project)

## Documentation Maintenance Rules
1. **Root `README.md` Integrity:** Always maintain `README.md` at the workspace root containing clear installation steps, execution commands, test steps, and component previews.
2. **Timestamped Logbook Ledger (`.agents/LOGBOOK.md`):** Record timestamped work progress (`YYYY-MM-DD HH:MM IST`), remaining backlog, failed experiments (with root cause & resolution), and **Decision Rationale** (why a feature was built, original plan vs. pivot, why an approach was abandoned).
3. **Continuous Updating:** Whenever finding code drift between system execution and `README.md`, update `README.md` immediately.
