# Global Agent Rule: Human-in-the-Loop & Decision Control

> **Scope:** Generic User Standard (Portable to any project)

## Interaction Standards
1. **User Control First:** Never execute high-risk or external actions automatically without user review.
2. **1-Word Command Inputs:** Provide concise 1-word or 1-letter user controls (`REFER`, `APPLY`, `SKIP`, `g`) to make manual decision-making effortless.
3. **Quantifiable Decision Data:** Always compute explicit scores, metrics, and deltas accompanied by 🟢/🟡/🔴 visual health indicators to empower user decisions.
4. **Scannable Outputs:** Format user-facing text for fast scanning on mobile and desktop screens.
